COMMAND COPIED · NEXT STEPS

命令已复制，接下来这样操作

请回到需要处理的 Mac，按照当前所处环境打开终端并运行刚刚复制的命令。

  1. 打开终端

    根据桌面模式或 Recovery 的入口找到“终端”。

  2. 粘贴命令

    在终端中按 Command + V 粘贴，然后按 Return/回车运行。

  3. 按提示完成

    选择语言、阅读并确认声明，再根据终端提示选择系统卷或输入管理员密码。

正常桌面系统打开“应用程序 → 实用工具 → 终端”。
macOS Recovery从顶部菜单打开“实用工具 → 终端”。

Recovery 入口与终端位置

找不到磁盘或磁盘仍未装载

返回 Recovery 的磁盘工具，展开卷组，选择灰色的 Data/数据卷并点击“装载”，需要时输入 Mac 管理员密码，然后回到终端重试。

完成后注意

看到设备注册或远程管理页面时，不要进入注册详情；请按照终端结果和页面上的继续/返回提示操作。
