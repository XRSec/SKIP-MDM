不同模式说明（科普）

点击展开

恢复模式：

  1. 英特尔 CPU 通常是 长按 Command + R 进入
  2. Apple CPU 通常是 长按 电源键 进入
  3. 终端在：启动台 -> 实用工具 -> 终端

桌面模式：

  1. 正常开机的页面就是桌面模式
  2. 终端在：通知栏 -> 其他/实用工具 -> 终端

Hello / 开始页面（设置助理）：

  1. 装系统的时候选择语言那个界面
  2. 先按几次继续，然后 按住 Command + Q 出现 关机选项

DFU刷机：

  1. 不到万不得已没必要选择DFU
  2. DFU 是刷机速度最快的模式
  3. 视频教程: b23.tv/BV1Ji421C7Tz

温馨提示

温馨提示 -> 查看更多

禁用SIP: 需要先关机，再进入恢复模式，现在我们不需要禁用SIP

清理监管: 需要联网 移动网络经常出问题，建议切换电信网络

全新安装: 尽量使用macOS 12的安装U盘 如果不行，则可以尝试 DFU 安装。安装完之后切记断开网络 或者拔掉路由器电源

重装/升级: 重装需要再绕过监管，升级则不需要

系统版本: 目前无要求

最后测试

测试项目：
  1. 登录 Apple ID 开启查找 测试查找
  2. 有iPad的测试 随航 功能是否正常
  3. iPhone 测试粘贴板是否正常
  4. iPhone 测试 是否能让电脑播放音乐（手机播放音乐，切换播放设备为电脑）
