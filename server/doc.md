## 不同模式说明

<details> <summary style="color: red">点击展开</summary>
<h3>恢复模式：</h3>
<ol>
<li>英特尔 CPU 通常是 长按 <code>Command + R</code> 进入</li>
<li>Apple CPU 通常是 长按 <code>电源键</code> 进入</li>
<li>终端在：启动台 ->; 实用工具 ->; 终端</li>
</ol>
<h3>桌面模式：</h3>
<ol>
<li>正常开机的页面就是桌面模式</li>
<li>终端在：通知栏->; 其他/实用工具 ->; 终端</li>
</ol>
<h3>Hello / 开始页面：</h3>
<ol>
<li>装系统的时候选择语言那个界面</li>
<li>先按几次继续，然后 按住 Command + Q 出现 关机选项</li>
</ol>
<h3>DFU刷机：</h3>
<ol>
<li>不到万不得已没必要选择DFU</li>
<li>DFU 是刷机速度最快的模式</li>
<li><a href="https://b23.tv/BV1Ji421C7Tz" target="_blank" style="padding: 0">视频教程: b23.tv/BV1Ji421C7Tz</a></li>
</ol>
</details>

## 温馨提示

![须知1](https://xrsec.s3.bitiful.net/MDM/须知1.jpg?fmt=webp&q=48&w=500)

![须知2](https://xrsec.s3.bitiful.net/MDM/须知2.jpg?fmt=webp&q=48&w=500)

<details> <summary style="color: red">温馨提示 -> 查看更多</summary>
<p><strong>禁用SIP</strong> 需要先关机，再进入恢复模式，<font color="red"><strong>现在我们不需要禁用SIP</strong></font></p>
<p><strong>清理监管</strong> 需要联网 移动网络经常出问题，建议切换电信网络</p>
<p><strong>全新安装</strong> 尽量使用macOS 12的安装U盘 如果不行，则可以尝试 DFU 安装。安装完之后切记断开网络 或者拔掉路由器电源</p>
<p><strong>重装/升级</strong> 重装需要再绕过监管，升级则不需要</p>
<p><strong>系统版本</strong> 不建议吃螃蟹，建议使用 Monterey 或者 Ventura</p>
</details>
